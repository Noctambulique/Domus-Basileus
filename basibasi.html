Comment ajouter vos propres pages

Modifiez simplement le tableau searchIndex dans le script plus bas. Chaque entrée représente une page cible et la liste des mots ou expressions qui peuvent y renvoyer.

Le moteur fonctionne même si l'utilisateur colle un long texte : il cherche si un ou plusieurs mots-clés sont présents dans la requête. 

// Exemple à compléter
{
  title: "Page Jean Dupont",
  url: "pages/jean-dupont.html",
  description: "Page personnalisée pour Jean Dupont.",
  keywords: ["jean dupont", "dupont", "jean", "professeur dupont"]
}
